## Built With
- Unity 6.5
- C#

## How to Run
1. Install Unity Hub and Unity 6.5. (The exact version is in `ProjectSettings/ProjectVersion.txt`. It will look something like `6000.5.x`.)
2. Clone this repo: `git clone https://github.com/forbidynaliew/NepaliSauce.git`
3. In Unity Hub click **Add → Add project from disk** and select the cloned folder.
4. Open the project, load the main scene, and press Play.
